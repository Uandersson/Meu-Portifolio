# Meu Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, experiências, projetos e conhecimentos na área de Tecnologia da Informação.

Este projeto está sendo desenvolvido como forma de colocar em prática meus conhecimentos de desenvolvimento web e, principalmente, acompanhar minha evolução durante os estudos.

Além de apresentar meus projetos, o portfólio será utilizado para praticar:
